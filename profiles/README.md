# Profiles

Per-title launch contracts. The launcher matches an install to one of these JSON files and passes it to the runtime. No title-specific `if` in app code.

- Schema: [`_schema.json`](_schema.json)
- First: [`apex-legends.json`](apex-legends.json)
- Second: [`marvel-rivals.json`](marvel-rivals.json)
- Later: [`spider-man-remastered.json`](spider-man-remastered.json)

How to add a title: `.cursor/skills/title-profile/SKILL.md` and `docs/GAMES.md`.
