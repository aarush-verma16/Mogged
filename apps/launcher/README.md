# Launcher

This is the product: a native macOS desktop app.

**Status:** not started. **M1.**

## Intended shape

- Swift + SwiftUI, Apple Silicon only.
- Loads `profiles/*.json`.
- Detects installs; Play / Stop.
- Looks like a game launcher. Does not look like developer tooling.
- Talks to `runtime/` as a local helper.

See `.cursor/rules/launcher.mdc` and `docs/ARCHITECTURE.md`.
